# Özel Tarama Modu #

*	Yazarlar: Noelia Ruiz Martínez, Ever Solis

Bu eklenti, tarama modunun durumuna bağlı olarak profilleri etkinleştirmek veya devre dışı bırakmak için kullanılır.

Şu anda, tarama modu etkin olduğunda, browseMode adlı bir profil etkinleştirilecek ve tarama modu devre dışı kaldığında bu profil de devre dışı bırakılacaktır.

Eğer mevcut değilse, browseMode profili otomatik olarak oluşturulacaktır.
