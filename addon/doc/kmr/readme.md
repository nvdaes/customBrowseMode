# Moda Geroka Xweser #

*	Nivîskar: Noelia Ruiz Martínez, Ever Solis

Ev pêvek ji bo çalakkirin an neçalakkirina profîlan li gorî rewşa moda gerokê tê bikar anîn.

Niha, dema ku moda gerokê çalak be, profîlek bi navê browseMode dê were çalak kirin, û dema ku moda gerokê neçalak bibe dê were neçalak kirin.

Profîla browseMode heke tune be dê bixweber were afirandin.
