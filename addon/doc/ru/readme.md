# Пользовательский Режим Обзора #

*	Автор: Noelia Ruiz Martínez, Ever Solis

Это дополнение используется для активации или деактивации профилей в зависимости от состояния режима обзора.

В настоящее время, когда активен режим обзора, будет активирован профиль с именем browseMode, и он будет деактивирован, когда режим обзора станет неактивным.

Профиль browseMode будет создан автоматически, если он ещё не существует.
